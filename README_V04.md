# CHK Crypto v0.4 — Refonte UX

## Changements principaux

- Nouveau dashboard global Binance + Bybit.
- Navigation basse plus claire : Accueil, Actifs, PRU, Notes, Réglages.
- Sélecteur Binance / Bybit visible en permanence.
- Cartes portefeuille plus lisibles et hiérarchisées.
- Historique / PRU transformé en blocs visuels.
- Bloc-notes refondu avec catégories et filtres : ACHAT, VENTE, ALERTE, PLAN, NOTE.
- Nouveau formulaire « Plan d'ordre » pour préparer un ordre limite sans l'exécuter.
- Connexions API regroupées dans Réglages avec état de synchronisation.
- Nouveau logo CHK Crypto intégré à l'APK et aux notifications.
- Aucune fonction de retrait ou transfert.
- En v0.4, aucun ordre n'est encore envoyé : les plans d'ordre restent des brouillons.

## Étape suivante

La prochaine étape prévue est le flux sécurisé Bybit : Spot Limit uniquement, demande de confirmation par e-mail, puis exécution après validation explicite.
